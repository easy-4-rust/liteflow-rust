# LiteFlow → liteflow-rust 功能语义迁移对照表

基线：dromara/liteflow **v2.16.0**（liteflow-core），已覆盖 v2.13.2 → v2.16.0
的全部新增语义（execute2RespWithEL / ExecuteOption / FlowEvent / Slot attachment /
Condition 级 bind / NodeId 校验 / AND-OR isAccess 过滤 / execute2RespWithRid）。

迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的 Spring 容器、反射实例化、ThreadLocal 上下文、CopyOnWriteHashMap、
CompletableFuture 分别映射为：显式注册表、trait 对象、Arc 共享上下文、
DashMap、tokio JoinSet。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ⬜ 未迁移（路线图）

## 一、EL 编排语义（core 核心价值）

| Java 类 | 语义 | Rust 实现 | 状态 |
|---|---|---|---|
| ThenCondition | pre→主体顺序执行→finally；异常记 slot 并抛出；finally 必执行 | `El::Then` / `exec_then` | ✅ |
| WhenCondition | 并行执行 | `El::When` + tokio JoinSet | ✅ |
| AllOfParallelExecutor | 全部完成 | 默认策略 | ✅ |
| AnyOfParallelExecutor | 任一成功即返回（`ANY(true)`） | ✅ | ✅ |
| PercentageOfParallelExecutor | 按比例成功（`PERCENTAGE(p)`，向上取整） | ✅ | ✅ |
| SpecifyParallelExecutor | 指定分支成功（`MUST("id")`） | ✅ | ✅ |
| ParallelStrategyHelper | `OnceLock + RwLock<HashMap>` 缓存四类无状态执行器，`WhenCondition` 统一从 Helper 装配 | ✅ |
| IfCondition | 条件节点结果驱动分支；isAccess=false 直接返回；目标不可 pre/finally | `exec_if` | ✅ |
| SwitchCondition | "id:tag" 目标匹配规则；default；NoSwitchTargetNodeException | `exec_switch` | ✅ |
| ForCondition | 计数循环、DO/BREAK、PARALLEL 并行提交+启动期 BREAK 检查 | `exec_for` | ✅ |
| WhileCondition | 条件循环（含并行形态） | `exec_while` | ✅ |
| IteratorCondition | 迭代循环，loopObject（含并行形态） | `exec_iter` | ✅ |
| CatchCondition | 捕获执行 DO；无 DO 继续抛出 | `exec_catch` | ✅ |
| FinallyCondition / PreCondition | THEN 内特殊键位 | `El::Pre` / `El::Fin` | ✅ |
| RetryCondition | 重试 retryCount 次（总尝试 retryCount+1） | `El::Mods.retry` | ✅ |
| TimeoutCondition | MAX_WAIT_SECONDS/MILLISECONDS | `El::Mods.max_wait_ms` / WhenOpts | ✅ |
| AndOrCondition | AND/OR 布尔短路 | `El::And` / `El::Or` | ✅ |
| NotCondition | NOT 取反 | `El::Not` | ✅ |
| ignoreError | 条件级/节点级错误吞掉 | WhenOpts / Mods.ignore_error | ✅ |
| NodeInstanceId 管理（同一节点多次出现的实例编号） | `flow::instance_id` 四对象：SPI、基类、文件默认实现、Holder | ✅（MD5 + serde JSON 文件持久化、查找/恢复、自定义 SPI 替换均已真实测试） |
| ChainBindWrapperCondition | 子链包装，EL 直接引用子链 id（builder 解析节点时自动识别） | ✅ |
