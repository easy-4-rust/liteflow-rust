> 版本：v1.0（2026-07-25）｜基线：dromara/liteflow v2.10.0（模块边界）+ v2.16.0（语义超集）

## 一、总目标

以 dromara/liteflow 为蓝本，实现能力完全对齐的 liteflow-rust workspace。当前为
9 个顶层 crate/聚合模块、63 个 workspace crate：

| crate | 对应 Java 模块 | 状态 |
|---|---|---|
| liteflow-core | liteflow-core | 🚧 进行中（结构 ~40%，语义 ~95% 主干） |
| liteflow-derive | annotation/ + 声明式组件 | ✅ 独立 proc-macro crate，S4 完成 |
| liteflow-rule-plugin | liteflow-rule-plugin（6 类规则源） | ✅ 独立 crate，S5 完成 |
| liteflow-script-plugin | liteflow-script-plugin（7 类语言入口） | ✅ 独立 crate，S5 完成 |
| liteflow-vernal | liteflow-spring / Boot 3+4 starter / Solon / Web 入口 | 🔶 Spring、Boot 3+4、Solon 对象清单已落位并接入 Vernal，Axum/Actix 主链已接通；真实 JVM/生产部署仍待验证 |
| liteflow-el-builder | builder/el（ELBus 链式 API） | ✅ 独立 crate 已落地，core operator 36/36 完成 |
| liteflow-agent | liteflow-ai-agent | ✅ AgentScope ReAct + 4 个 provider 子 crate，S7 完成 |
| liteflow-benchmark | liteflow-benchmark | ✅ 与 Java POM 一致的 8 个子模块，S8 完成 |
| liteflow-testcase-el | liteflow-testcase-el | ✅ 29 个 testcase 子模块，S8 完成 |

硬性规范（用户指定，全阶段适用）：
1. 目录/文件名 snake_case；类型 PascalCase；方法 snake_case；参数命名与 Java 一致
2. Java 子包 → Rust 同名子目录；多层嵌套只要求最后一级完全对齐
3. 注释从 Java 复制并中文化，标注对应 Java 类与方法
4. jackson→serde；Spring Boot→axum；Quarkus→actix；Spring 容器→easy-4-rust/vernal；Agent→agentscope-rust
5. 一文件一对象；禁止 lib.rs/compat.rs 堆积对象；禁止 compat.rs 转发式引用
6. annotation/ 独立为 liteflow-derive（过程宏 crate）
7. 模板引擎速记：Tera≈FreeMarker、Handlebars≈Velocity、Askama≈编译期 JSP/Thymeleaf、maud≈Twirl/JSX
8. 功能语义对齐，实现方式 Rust 化
